# How do I add a venue?

Venues let you track where you play and pull in historical weather data for each game.

## Adding a venue when logging a game

The easiest way to add a venue is right from the **Log a Game** screen:

1. In Step 3 (Game Details), open the **Venue** dropdown.
2. Select **+ Create new venue** at the bottom of the list.
3. Type a name (e.g. "Backyard at Mike's").
4. Hit **📍 Set My Location** to pin its coordinates — this enables weather tracking.
5. Submit the game as normal.

The venue is saved and will appear in the dropdown for all future games.

## Pinning coordinates to an existing venue

If a venue is missing coordinates (you'll see a 📍? next to its name), you can pin it:

1. Select that venue while logging a game.
2. A prompt appears: **"No location saved for this venue."**
3. Tap **📍 Pin This Venue** to save your current GPS location.

Coordinates are shared across the league — once one person pins a venue, everyone benefits.

## Why does location matter?

Location enables automatic weather data for each game. After a game is logged with a valid venue, the app fetches the historical weather conditions (temperature, conditions, wind) and displays them on the game detail page.
