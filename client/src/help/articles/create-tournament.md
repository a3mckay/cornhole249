# How do I create a tournament?

Tournaments are a Pro feature. If your league is on a Pro plan or Weekend Pass, here's how to run one.

## Setting up a tournament

1. Go to **Tournaments** from the nav.
2. Click **New Tournament**.
3. Give it a name, pick the format (single elimination or round robin), and select the players.
4. Click **Create** — brackets are generated automatically.

## Recording results

Open any match in the bracket and enter the scores. The bracket updates in real time for everyone in the league.

## Tips

- You can run multiple tournaments simultaneously — useful for 1v1 and 2v2 at the same event.
- Scores logged through the tournament count toward season stats and Elo ratings.
- If you need to correct a score, open the match again — admins can edit results.
